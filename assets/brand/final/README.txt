PRINT / PDF
  Open "AZEB Logo Kit" and use Export to save a two-page PDF
  (logo sheet + usage guide). The SVGs print at any size.

TYPE
  Inter Tight (SIL Open Font License, free for all use).
  AZ ELEVATED = Bold; BUILDERS = SemiBold, wide-tracked between rules.
  Kerning OFF.
  The horseshoe U is a DRAWN VECTOR GLYPH, not type - elliptical band,
  flared heels, fuller groove. Never substitute a letter U.
  In the SVGs the wordmark is live text: convert it to outlines before
  sending artwork to a printer.

MARK
  Interlocked A and Z. The top bar passes BEHIND the right leg; the
  diagonal passes OVER it. The weave slits and flat feet are part of
  the mark - never close them up.

USE
  Minimum sizes: mark 24 px tall; stacked logo 108 px wide.
  Below 108 px wide, drop the wordmark and use the mark alone.
  Clear space on all four sides: one third of the mark's height.
  Colour: black #000000 or white #FFFFFF only. No colour, gradients,
  shadows or outlines. Never stretch, rotate or redraw any part.
